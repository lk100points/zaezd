# 🚗 Заезд в Одинцово — Remastered v3 (three.js, 3D)
Играется и **горизонтально, и вертикально**, на ПК и телефоне. Нужен интернет (three.js грузится с CDN). Запуск: GitHub Pages или `python3 -m http.server` → `index.html`.
Если вдруг экран чёрный — вверху покажется красная строка с ошибкой, пришли её.
- **Карты (8):** Зима/Одинцово, Золотая осень, Лето, Весна/сакура, Minecraft (блоки), Mirage (пустыня), GTA VI (Vice City), Cyberpunk (Night City) × 4 времени суток.
- **Гараж:** скины машин (в т.ч. «Пантера КОЧ»), шины, дробовики, следы, **нитро-скины** (цвет и пламя), карты, время, прокачка.
- **Графика:** суперкар с диском/суппортами/антикрылом, тени, bloom, цветокор, отражения, объёмные фары, камни/фонари/отражатели.
- **Геймплей:** толкайся и таранься, смерть только от сильного удара об обочину; дрифт, нитро, дробовик, взрывы.
**ПК:** ←→/AD руль · S тормоз · Shift нитро · C вид · G дробовик · ЛКМ/пробел огонь · R перезарядка.
**Телефон:** ◀ ▶ или свайп по левой половине, тап справа — дробовик/выстрел; ТОРМОЗ, НИТРО, ВИД, R.
